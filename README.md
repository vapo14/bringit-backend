# Bringit Core Backend Service

## Summary
Bringit was meant to be a mobile application that allows users to create events with lists of items to bring. Let's say you're planning a birthday party, and you want guests to bring specific things like drinks, paper plates, and napkins. 
Bringit would allow you to share your event with your guests and let them assign an item to themselves. That way, everyone knows what to bring!

Unfortunately, I haven't been able to dedicate much time to building the project, but I hope I'll finish it in the near future. 

The backend is a simple CRUD monolith. I really don't have much reason to build anything beyond that, as this is a side project.
